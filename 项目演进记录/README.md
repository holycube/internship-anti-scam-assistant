# 项目演进记录

> 完整使用方法见根目录 [`README.md`](../README.md)；本文件只说明这个目录本身是什么。

本目录保留早期「单文件脚本」形态，用来说明本工具如何演变成现在的结构化流水线。

## 演进路径

```mermaid
flowchart LR
  A[旧版单脚本] --> B[分模块工具链]
  B --> C[画像打分与过滤规则]
  C --> D[企业核验与踩坑闭环]
```

| 阶段 | 形态 | 说明 |
|---|---|---|
| 旧版 | `旧版_scrape_shixiseng.py` + `旧版_filter_jobs.py` | 采集、打分、渲染挤在少数脚本里，输出本地 md/html |
| 现版 | `工具/` 下多脚本 + `配置/` JSON | 批次目录、统一字段、可配置画像/过滤规则、分平台导出 |
| 防诈骗增强 | `工具/企业核验.py` + `踩坑案例库/` | 联网核验发薪主体一致性、业务与任务错配；真实案例反哺规则 |

## 本目录文件

- [`旧版_scrape_shixiseng.py`](旧版_scrape_shixiseng.py) — 早期实习僧采集与匹配渲染
- [`旧版_filter_jobs.py`](旧版_filter_jobs.py) — 早期二次过滤

**不要直接依赖这些脚本跑生产流程**；请使用仓库根目录 `工具/` 下的当前版本。

旧版里的打招呼草稿、真实岗位全量 JSON 等个人投递材料**未迁入**本仓库。
