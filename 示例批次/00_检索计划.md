# 检索计划 · 示例批次

## 本批目标

- 时间范围：过去一周内新增。
- 工作形式：线上、远程、不坐班的兼职或实习。
- 优先方向：Word / Excel / Office / WPS、Notion / 飞书、知识库与文档维护、AI / Cursor / Agent / API 接入、测试 / QA / 自动化。
- 排除：低价值数据标注、短视频、种草、教培及 `配置/过滤规则.json` 中的硬过滤项。

## 平台边界

- **实习僧**：公开 API，检索词使用 `publishTime=week`，仅保留明确远程岗位。
- **Boss**：不扫描搜索页；把人工找到的职位详情链接粘贴到批次内 `Boss待抓链接.txt` 后采集。
- **拉勾**：尝试公开搜索页 1–2 页；解析失败时保存空结果和真实说明，不伪造岗位。

## 流水线

1. 采集各平台 → `01_原始_*.jsonl`
2. `打分.py` → `02_已打分.jsonl`
3. `过滤.py` → `03_已过滤.jsonl` + `03_人工浏览.md`
4. `分平台导出.py` → `平台结果/<平台>/`
5. 人工精简 `04_短名单.jsonl`
6. `核查链接.py` 保守核查短名单
7. （可选）`企业核验.py` 联网核验公司真实性 / 发薪主体一致性 / 业务与任务是否错配
8. 在 `打招呼/` 起草话术
