# 话术模板范例

用人设：示例用户｜本科在读｜每周约 3–4 天可远程｜熟 Word/Excel/Notion/飞书｜常用 Cursor / AI。

**写法**：前两句＝远程 + 立刻能干的事；第三句＝时间；收尾＝一个具体问题。平台私信约 80–120 字；邮件类 300–500 字。

---

## 知识库 / Agent 类

> 您好，看到贵司【岗位名】（远程）。我日常用 Notion/飞书做文档与知识库整理，也常用 Cursor/AI 做结构化改写与小链路对接；每周可稳定投入 3–4 天。方便了解日常交付形式和带教方式吗？

## 产品助理类

> 您好，看到贵司产品助理（远程）岗位。我能做竞品/资料调研与流程文档整理，飞书、Notion、Office 都熟，也会用 AI 提效做表格和材料结构化；每周可稳定 3–4 天。方便聊聊带教与是否有实习补贴吗？

## 增长 / 运营助理类

> 您好，看到贵司增长/运营实习（远程）。我能做基础竞品与内容整理，飞书、Notion、Office 都熟，也会用 AI 提效做表格和文档。想确认下是否接受在校生、远程日常怎么协作？

## 开发类

> 您好，看到贵司应用/全栈开发（远程）。我有 Python/脚本与 Cursor 提效开发基础，也接触过 API 小链路。想确认主要技术栈、是否接受在校生、远程如何带教？每周可稳定 3–4 天。

## 内容 / 编辑类

> 您好，看到贵司编辑助理（远程）。Word/文档校对与结构化整理比较细，也能配合飞书协作。时间可按周稳定投入，方便了解日常主要做哪类稿件吗？

## 邮件自荐（行政 / 助理类）

主题：`[岗位]-[姓名]-[学校全称]-[可实习X个月，每周约Y天]`

> HR 好，
>
> 我是【学校】【专业】在读学生【姓名】，看到贵司线上实习招聘，想申请**行政**岗位。
>
> 我平时负责【社团/班级/项目中的一件真实小事】，用 Excel 做过数据统计和排期表，也用飞书多维表格搭建过【任务看板/打卡表等】，协作和纪要都在飞书上完成。日常用 Cursor / ChatGPT 处理重复性整理，例如把散乱文档结构化成表格或知识库条目。
>
> 我可以远程稳定投入，每周约 4 天，起可实习 4 个月。附件是简历，方便的话希望能进一步聊聊。
>
> 谢谢！
> 【姓名】

## Boss 项目制（先问无付费 / 结算）

> 看了岗位，智能体/知识库对接方向比较匹配，API 与文档整理能上手，项目制远程时间可配合。结算和交付节点方便说下吗？有无任何付费/押金要求？
