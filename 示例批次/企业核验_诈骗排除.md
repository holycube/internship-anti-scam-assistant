# 企业核验 · 诈骗/高危排除（示例说明）

本文件演示核验报告的写法。真实批次请在 `日期/<批号>/平台结果/` 下生成同名文件。

## 判定规则

1. **联网核验建议「排除/高危」** → 默认移出可投递
2. **核验「可投/慎投」但岗位形态高危**（居家 Excel/文职刷量、校园推、讲课收费）→ 人工仍排除
3. **检索未命中、但有公开工商/融资证据** → 可人工复判保留（避免 lite 模型误杀）
4. **发薪主体与招聘主体不一致，或业务与任务明显错配** → 直接高危（见踩坑案例库）

## 人工复判保留（示例）

| 公司（占位） | 原因 |
|---|---|
| 示例智能硬件公司 | 有公开融资/工商信息，岗位与主业匹配 |
| 示例增长科技公司 | 有公开合作信息，人工确认可远程 |

## 排除类型摘要（示例）

- 居家文员 / Excel / 无清晰主体
- 教培 / 职介 / 付费内推风险
- 主体虚、模板可疑
- 业务与岗位严重错配（如孕妇学校挂 RAG 岗、环保公司安排电商链接整理）
- **真实样板**：茹美达运营助理 — 发薪方为武汉新鑫明宇环保科技有限公司，与招聘主体不一致，任务为整理京东商品链接。详见 [`../../踩坑案例库/案例/2026-07-18_运营助理岗位诈骗信号案例.md`](../../踩坑案例库/案例/2026-07-18_运营助理岗位诈骗信号案例.md)

## 防骗红线

缴培训费、押金、购物卡、不明 App、私人转账 → 一律终止。
