# 过程归档示例

> 完整使用方法见根目录 [`README.md`](../../README.md)；本文件只说明这个目录本身是什么。

下列 JSONL 为**精简重建**的数据格式样例（每阶段 2–3 条），不是全量抓取结果。

| 文件 | 阶段 |
|---|---|
| `01_原始_示例.jsonl` | 采集后的标准化岗位 |
| `02_已打分.jsonl` | 按画像打分后 |
| `03_已过滤.jsonl` | 硬过滤后保留项 |
| `04_短名单.jsonl` | 人工精简后的可执行清单 |

其中「茹美达」条目故意保留在 `01`/`02` 中，表示：匹配分可能不低，但仍应在企业核验阶段因发薪主体不一致 / 业务错配被排除。详见踩坑案例库。
