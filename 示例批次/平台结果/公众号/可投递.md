# 公众号渠道 · 可投示例

说明：公众号正文多数需微信内打开。本表示意如何按画像筛选远程 / Office / 飞书 / Notion / AI / 知识库类岗位，并排除新媒体 / 销售 / 付费实习等。

## 优先可投（示例）

### 1. 示例咨询科技公司 · 线上行政 / 咨询助理

| 项 | 内容 |
|---|---|
| 地点 | 全程线上 |
| 时长 | 至少 3 个月（建议 6 个月） |
| 投递 | 简历 + **必填自荐信** → `hr@example-company.com`（仅用官网域名邮箱） |
| 邮件主题 | `[岗位名称]-[姓名]-[学校]-[可实习时长]` |

**自荐信必写：** 为何投该岗；飞书/文档/表格协作实事；AI 工具使用场景；可实习时长与每周天数。

**不建议投：** 新媒体运营、销售、商务、需缴费的「训练营式实习」。

## 长期可关注的信息源类型（非单次岗位）

| 类型 | 用途 |
|---|---|
| 企业自有公众号 | 线上实习公告原文 |
| 远程岗位聚合社区 | 需自行甄别门槛与付费陷阱 |
| 高校就业网「远程」标签 | 企业公告转载入口 |

## 防骗提醒

- 邮箱域名须与公司官网一致；勿信第三方「代投」。
- 要求培训费 / 押金 / 购物卡 → 立即终止。
