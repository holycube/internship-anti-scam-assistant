# 示例批次说明

> 完整使用方法（换爬取方向、命令详解、运行环境）见根目录 [`README.md`](../README.md)；本文件只说明这个目录本身是什么。

本目录是用**占位符公司名与示例链接**重建的流水线产出样例，用来演示工具从采集 → 打分 → 过滤 → 分平台导出 → 企业核验的完整形态。

- 不是某次真实投递记录；真实个人数据请在本地 `日期/YYYY-MM-DD-NN/` 批次中维护（该目录由 `工具/新建批次.py` 创建，默认被 `.gitignore`）。
- 公司名形如「示例智能硬件公司」「示例 SaaS 公司」；链接统一为 `https://example.com/...`。
- 诈骗/高危手法的**真实案例样板**见 [`../踩坑案例库/`](../踩坑案例库/)（茹美达案例保留公开可查的真实公司名与证据截图）。

## 目录

| 路径 | 用途 |
|---|---|
| `00_检索计划.md` | 本批检索意图模板 |
| `平台结果/*/可投递.md` | 分平台保留岗位示例 |
| `企业核验_诈骗排除.md` | 核验判定规则与示例结论 |
| `话术模板范例.md` | 按岗位方向分类的打招呼模板（非真实对话） |
| `过程归档/原始采集/` | 各阶段 JSONL 精简示例（每阶段 2–3 条） |
