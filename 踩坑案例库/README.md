# 踩坑案例库

> 完整使用方法见根目录 [`README.md`](../README.md)；本文件只说明这个目录本身是什么。

与「能力验证方法论」对称：一边沉淀「验证过该投」的能力信号，一边沉淀「验证过该排除」的高危手法。

**公开仓库约定**：案例正文只写手法与规则，**不写真实公司全称、个人收款信息、可识别截图**。证据附件仅留本机（`案例/附件/` 已 gitignore）。

每条案例尽量包含：岗位形态、异常如何发现、核验结论（可脱敏）、提炼出的可复用规则。写法见 [`案例/2026-07-18_运营助理岗位诈骗信号案例.md`](案例/2026-07-18_运营助理岗位诈骗信号案例.md)。

提炼出的红线规则会写进 [`配置/过滤规则.json`](../配置/过滤规则.json) 的 `risk_flags`，并由 [`工具/企业核验.py`](../工具/企业核验.py) 在联网核验时使用。
